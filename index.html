PDF Casero

PDF Casero es un lector y editor de PDF para Windows de uso familiar y privado. Permite leer PDF, reconocer el texto de documentos escaneados, editar texto, dibujar y organizar páginas.

Opcionalmente, cada persona puede conectar su propia cuenta de Google para enviar un documento a Google Docs o sus tablas a Hojas de cálculo de Google, editarlo allí y traerlo de vuelta como PDF.

Uso de los datos de Google: Política de privacidad.
